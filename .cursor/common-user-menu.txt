- File Managers
- Media Players
- Office and Productivity
- Gaming
- Communication
- Graphics and Design

  --> Programming Languages
  --> Version Control

### Utility Modules (Essential)
- Utilities (Command Replacements only)
  --> Command Replacements
  --> Archive and Compression
